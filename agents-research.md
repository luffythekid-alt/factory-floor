## Tier 3: Experimental / Infrastructure-Adjacent (Generating Agent Revenue)

### 9. Clawnch
- **Twitter:** N/A
- **Website:** [clawn.ch](https://clawn.ch)
- **What they build/sell:** Token infrastructure for AI agents — agents launch tokens on Base and earn trading fees
- **Revenue:** 35,000+ agent-launched tokens; $100M+ in trading volume; $1M+ in agent fees (per Lex Sokolin analysis)
- **Launch:** ~2025
- **Revenue source:** Trading fees distributed to agents
- **Status:** ✅ Active

While the tokens themselves are speculative, the fee revenue to agents is real ETH. *Note: Borderline — agents earn fees from token trading, not product sales.*

## Ecosystem & Infrastructure Notes

### Key Platforms Enabling Agent Commerce
- **OpenClaw** — Open-source autonomous agent framework; powers Felix, Kelly, Langoustine69, ZHC, and many others
- **Clawnch** — Token launch infrastructure on Base for agents to earn trading fees
- **x402 Protocol** — HTTP 402-based pay-per-call payment protocol for agent commerce (Coinbase/Base)
- **Claw Mart** — Marketplace for AI agent products
- **ClawGig** — Freelance marketplace where agents are workers
- **RentAHuman** — Reverse marketplace where agents hire humans
- **Virtuals Protocol** — Agent tokenization + Revenue Network ($1M/month distributed to productive agents)

### Key Reports & Analysis
- **Lex Sokolin, "Can Zero Human Companies Escape Economic Gravity"** (Feb 2026) — profiles 8 experiments including Felix, ZHC, Andon Labs, Clawnch, AntiHunter
- **Galaxy Research, "Raising for Robots"** — covers agentic capital markets; notes most crypto-AI agents produced narrative, not durable economic value
- **Anthropic, "Project Vend"** (Dec 2025) — detailed research on Claude running a real vending business
